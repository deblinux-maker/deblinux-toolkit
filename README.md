Deblinux Toolkit
Toolkit di manutenzione e diagnostica per sistemi Debian‑based, sviluppato in Gambas 3.

📌 Descrizione
Deblinux Toolkit è un’applicazione grafica progettata per semplificare operazioni di manutenzione, pulizia, diagnostica e gestione del sistema su distribuzioni Debian e derivate.
L’interfaccia è sviluppata in Gambas 3 e offre strumenti integrati per:

pulizia cache e file temporanei

manutenzione avanzata del sistema

gestione pacchetti

diagnostica hardware e servizi

utility varie per amministratori e utenti avanzati

Il software è distribuito con sorgente visibile ma non modificabile, secondo la licenza proprietaria inclusa nel repository.

🛠️ Requisiti
Debian 12 o superiore

Gambas 3.20+

Permessi amministrativi per alcune funzioni (sudo)

Pacchetti standard di sistema (apt, dpkg, systemctl)

🔧 Compilazione
Per compilare il progetto:

Installare Gambas:

Codice
sudo apt install gambas3
Aprire il progetto:

Codice
gambas3 Deblinux_toolkit.gambas
Dal menu Gambas:

Progetto → Compila

L’eseguibile verrà generato automaticamente da Gambas.
